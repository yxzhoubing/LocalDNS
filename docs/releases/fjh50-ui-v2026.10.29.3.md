# FJH50 / UI 2026.10.29.3

本次把 DNS 内核从 **FJH21** 升级到 **FJH50** 并完成整机迁移；界面侧只做与新内核对齐的最小改动，DNS 配置、规则、上游与外观全部沿用。

## 内核 FJH50

- 来源为 `LocalDNS_FJH50.zip`；运行目录 `localdns/bin/localdns` 与 `LocalDNS_FJH50_Binaries/localdns-amd64-v3` 是同一份程序，SHA-256 `0b8d1f9e…b325fc7`（6,047,256 B）。
- Alpine + musl 的运行方式不变：仍由 gcompat 的 `ld-linux-x86-64.so.2` 装载，并 `LD_PRELOAD=/opt/localdns/bin/glibc-shim.so` 补齐 `__res_init` 等 glibc 符号。现有 shim 对新程序仍然有效，不需要重新编译。
- 内核新增的能力都在后端内部：本地区（`home.arpa`、`.localdomain`、`use-application-dns.net`、反查区）与 ANY / META / XFR 特殊查询改为本地应答，后台任务新增 `zone_check` 计数，缓存快照标识升到 `v6`（旧快照会被识别为不支持并丢弃）。

## 接口兼容性核对

升级前在独立端口跑起 FJH50 实例，与现网 FJH21 逐项比对：

- **38 条接口路径**的 HTTP 状态码完全一致；**18 个关键接口**做完整结构比对，唯一差异是 `/api/v1/status` 新增 `background.zone_check`，没有字段被删除或改型。
- `/metrics` 的 27 个指标名完全一致（`localdns_upstream_response_latency_milliseconds` 只在有上游应答后才出现，属采样差异而非缺失）。
- 写路径按现有界面实际发送的载荷形状回环验证（写入刚读到的同一份内容）：上游分组 `POST /api/v1/upstream/config`、功能开关 `PUT /api/v1/features`、客户端别名 `PUT /api/v1/client-aliases`、本地名单 `PUT /api/v1/lists/{list}`、缓存参数 `POST /api/v1/cache/limits` 全部返回 200，且 `config/` 与 `rules/manual/` 的 MD5 前后完全一致。
- `POST /api/v1/system/restart` 自重启成功（PID 变化），重启后规则、开关、上游、别名不变。

## 界面适配

- **版本元数据**：`VERSION.json` 与 `_src/ui/version.json` 改为后端 `FJH50`、UI `2026.10.29.3`、发行标签 `fjh50-ui-v2026.10.29.3`；`frontend/index.html` 首帧内核角标同步为 `FJH50`，与 `verify-build.mjs` 的「首帧内核标签必须与 VERSION.json 一致」校验对齐。
- **分流结果标签**：补齐 FJH50 会写入查询日志的新 `domain_set` 取值 —— `local_any`、`local_reverse`、`local_meta`、`local_xfr`，以及此前一直缺标签的 `local_name`、`geosite_non_cn_upstream_error`。概览「查询处理结果占比」与日志列表不再显示原始英文键名。
- **工具链**：`install-ui.sh` 的同核心校验列表与 `package_ui.py` 的运行时模板白名单加入 `FJH50`，否则新内核的 UI 包会被判为异核心而拒绝安装。

## 迁移范围

- **保留**：`config/upstreams`、`rules/manual`、`config/subscriptions`、`config/settings/*`（含 `client_aliases.json`、`switches.json`、`cache.json`、`generated.json`、`route_refresh.json`、`querylog.json`）、`config/localdns.json`、`rules/online`、`ui/custom`、`ui/config.js`、`bin/glibc-shim.so`、`bin/configure-ui.py`、`bin/ui-updater`、`.ui-updater`。
- **重置**：`cache/`、`generated/`、`rules/compiled/`、`logs/`。其中 `rules/compiled/` 由内核启动时从 `rules/online` 重新编译（日志可见 `rebuilt [custom_cn, custom_non_cn, geoip_cn, geosite_cn, geosite_non_cn]`）。

- 规则计数与迁移前逐项一致：`block 42`、`force_domestic 88`、`force_foreign_fakeip 70`、`force_foreign_realip 30`、`geosite_cn 112708`、`geosite_non_cn 27469`、`custom_cn 1250`、`custom_non_cn 33`。

- UDP 与 TCP 53 解析正常，9099 面板与 9100 更新端正常，界面 6 个页面在 FJH50 上渲染无报错。
- 回退目录：`/opt/localdns.previous-fjh21-20261029-193610`（含原 FJH21 程序、UI 与旧缓存）。

## 升级说明

本次更换了 DNS 内核，**必须使用完整包替换目录**，不能用 `install-ui.sh` 只换界面：

1. 备份 `config/`、`rules/manual`、`rules/online`、`ui/custom`、`ui/config.js`、`bin/glibc-shim.so`、`bin/ui-updater` 与 `.ui-updater`；
2. 停 `localdns` 与 `localdns-ui-updater`，把原目录整体改名留档；
3. 展开 FJH50 运行目录，回填上述数据与设置，删除 `rules/compiled/`；
4. 启动内核（编译规则）后启动更新端，用 `--check` 与规则计数确认结果。
