# FJH50 / UI 2026.10.29.4

合并 PR #14（`feat/devices-dark-glass`），设备页从「双卡片」改为一整张深色玻璃表格。

## 变化

- **统一表格**：受控条目与未受控的活跃 IP 同表展示，不再左右分栏。
- **顶部统计**：设备总数 / 走 FakeIP / 走 RealIP / 未受控四项，并标注「受控 N · 未受控 M」。
- **筛选与排序**：策略 tab（全部 / 走 FakeIP / 走 RealIP / 未受控）带计数，支持别名搜索与按请求数、IP 排序。
- **行内操作**：单机 `FakeIP / RealIP` 双态胶囊、加入名单、别名弹窗、日志深链保持不变；新增多选批量条（批量设 FakeIP / RealIP / 移出名单）。
- **视觉**：新增 `.dev-dark` 一整套深色玻璃选择器，旧 `devices-*` 浅色样式与对应 markup 一并移除。
- **后端交互未改**：模式切换仍是串行写入 + 回读校验 + 回滚，名单保存保留并发保护。

## 验证

- `npm run build` / `typecheck` / 161 项单测 / `lint` / `verify:generated` 全部通过。
- 部署到 FJH50（192.168.8.2）后在深色主题下实际渲染：41 台设备、11 受控 / 30 未受控、别名与单机策略正常，内核未重启。

## 升级说明

本次仅更新前端界面，DNS 内核、配置、规则与上游不变；更新 UI 无需重启 DNS。
