# LocalDNS FJGIR / UI 2026.10.21.2

升级 FJGIR 核心，在「查询日志 → 审计控制」增加自定义日志存放位置。保留现有双皮肤、DNS 趋势、静态共享设置与 Mihomo / sing-box 配置编辑器。

## 日志目录

- 支持 `logs` 等相对路径，以及 `/var/log/localdns` 等服务器绝对路径。
- 显示实际位置、内存和磁盘占用及查询记录数；保存失败保留输入并显示原因。
- 保存期间阻止重复提交，目录变更前确认清空当前查询记录。
- 最新 2,000 条记录留在内存，其余压缩写入磁盘。**重启后目录设置保留，查询记录清空；切换目录也会清空当前记录，旧压缩文件留在原目录，不自动迁移。**
- 此设置控制 DNS 查询审计日志；启动脚本或 systemd 的运行输出仍按原服务配置处理。

## 下载与升级

| 文件 | 用途 |
|---|---|
| `LocalDNS_FJGIR_UI_2026.10.21.2_Full.zip` | FJGIR 三种架构内核、干净默认配置与当前 UI |
| `LocalDNS_UI_2026.10.21.2_Update.zip` | 更新现有界面，保留核心、配置与共享资源 |
| `LocalDNS_ProxyConfig_UI_2026.10.21.2_Service.zip` | 配置服务 1.6.0，本次沿用已验证的程序和安装器 |
| `SHA256SUMS.txt` | 三个下载包的校验值 |

**FJGAC 等旧核心需先升级到 FJGIR，才能启用自定义日志目录。普通 UI 更新不会升级内核。** 已有配置服务 1.6.0 可继续使用。

升级前将完整安装目录备份到本机；保留 `config/`（包括上游、订阅、功能开关、别名、审计和定时任务）、`rules/manual/`、`ui/custom/` 与 `ui/config.js`。先用原配置副本及独立端口验证新内核，再停服替换对应架构程序并安装 UI。已有配置和规则继续使用；完整包提供新安装所需的干净模板。

`memory_limit_mb` 由 FJGIR 兼容读取为 DNS 缓存容量，沿用原数值；新字段名为 `cache_memory_mb`。切换内核需要短暂重启 DNS，失败时恢复旧程序及备份。详见 [安装说明](../../INSTALL.md)。
