# FJH7T / UI 2026.10.31.1

修复名单类别切换和在线分流交互，合入 [PR #21](https://github.com/yyhoworks/LocalDNS/pull/21)。

## 改动

- 手机端「名单类别」下拉支持选择其它分组的名单，不再只改变下拉值却停留在旧名单。
- 连续选择、手动切组或切名单、切换规则页签和离开页面时，取消等待中的旧选择，清理观察器、点击监听和定时器；返回相关分组时不会被之前的操作自动跳转。
- 等待目标名单的兜底时间覆盖默认 10 秒 API 超时内的慢响应。
- 在线分流总数卡在「分组卡片」视图下会先切到「表格列表」，再展开并定位目标分组。
- 分流分组表头可用 Tab 聚焦、Enter / Space 展开或折叠；「全部更新」按钮保持独立操作。
- 移除不再使用的名单分组样式和旧表格第三列宽度约束。

## 验证

- `npm run --prefix frontend check`：构建、类型检查、22 个测试文件 / 178 项测试、lint、构建一致性及字体覆盖检查通过。
- 新增 5 项回归用例，使用真实名单渲染、工作台和 API 客户端，仅模拟网络响应与时间：普通跨组切换、连续选择、8.5 秒慢响应、手动切组取消旧选择、离开页面后返回不恢复旧选择。
- 手动切组与离页返回两个问题均先复现失败，再验证修复通过。

## 升级说明

- **UI 更新包**：更新界面资源，保留内核、DNS 配置、规则、上游、`ui/config.js` 和 `ui/custom/`，无需重启 DNS；更新后刷新页面。
- UI 更新包要求当前内核为 **FJH7T**，其它内核请先按照完整包的迁移说明升级。
- **完整安装包**：保留已发布 FJH7T 完整包的内核和默认配置，并加入本版 UI，适用于新安装和完整迁移。
- 两个 ZIP 均提供 `SHA256SUMS.txt` 校验，包内文件由 `MANIFEST.sha256` 覆盖。
