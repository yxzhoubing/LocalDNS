# FJH50 / UI 2026.10.29.6

设备页交互收敛、规则页分组区分、趋势卡视觉修复与全站 UI 审查整改。

## 设备页

- **操作区收成一个主按钮**：去掉与行内铅笔重复的「管理全部别名」、与新增流程重叠的「原文编辑」，只保留主色「+ 新增受控 IP」。
- **原文批量并入新增弹窗**：弹窗顶部「逐条添加 / 原文批量」切换，原文面板沿用整份名单编辑与下载。
- **铅笔改为单条改名**：点铅笔只改当前 IP 的别名，不再跳进完整的客户端管理弹窗；批量能力保留为独立的「批量别名」入口。
- **自动收录**：开关打开后，有查询记录但没有别名的活跃 IP 会自动写入别名表（占位名 `设备 <末段>`），只改名称，不加入受控名单、不改变解析策略。
- **配色回归主题变量**：设备页原先自带一套写死的深色值（`#141221`、`#f2eef7`、`#4ade80`、紫粉渐变活跃度条等），全部换成 `--text-*` / `--border-glass` / `--glass-*` / `--console-*` / `--primary`，浅色与深色两套皮肤通用。
- **图标统一**：`✎`、`⋯`、`⇅` 等字符换成 `icon('edit')` / `icon('more')` / `icon('chevron')`，并约束 14px 尺寸。

## 规则页

- 名单分组标签（核心分流 / 解析控制 / PCDN 抑制）改为小号半粗、组间加竖直分隔线，与可点页签明确区分。

## 趋势卡

- 页签 4 → 2：「延迟与异常」「请求量与缓存命中率」，`平均延迟` 与 `缓存命中率` 转为内部指标。
- `anomalyChart()` 里写死的 12 点折线换成真实采样曲线，Y 轴自适应、100ms 阈值线按需出现、峰值圆角标签。
- 上游延迟改为按 key 匹配（原先要求前后样本数量与顺序完全一致，任一上游增减就丢弃整个延迟点，导致曲线长期为空）。
- 平滑曲线控制点限制在相邻两点区间内，消除稀疏数据下的 V 形假跌。
- 首屏空白改为 shimmer 骨架屏，并尊重 `prefers-reduced-motion`。
- 说明文字从 `--text-3` 提到 `--text-2`；状态色写死值换成 `--console-danger` / `--amber` / `--glass-pill`。

## 概览

- 「链路健康」横条不再重复指标卡里的上游竞速均值，改显示国内池采纳节点。
