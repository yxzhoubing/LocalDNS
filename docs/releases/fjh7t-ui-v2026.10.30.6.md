# FJH7T / UI 2026.10.30.6

分流页两处整理：名单页签改成「一级选组、二级选名单」，在线分流按类型折叠成分组表。46 个在线来源从一张平表变成六个可折叠的组。

## 背景

- **名单页签**：12 个名单分三组，但组名和页签是同一层级，看不出谁是谁的标题；上一版把组名抬到页签上方，视觉上仍不理想。
- **在线分流**：46 个来源挤在一张平表里，「类型」只占一列，滚起来找不到边界；其中 GeoIP 非 CN 一组就有 18 个来源、57.7 万条规则。

## 改动

### T1 · 名单管理改成两级切换

一级是三个分组（核心分流 / 解析控制 / PCDN 抑制），做成一条分段控件；二级是该组的名单，仍是描边胶囊。点一级只换二级的名单，并把编辑区切到该组第一个名单。

- 任何时候最多 3 + 4 个按钮，不会挤成两行。
- 组与组不再需要靠分隔线区分——它们根本不在同一层。
- 页面结构没变，`.rule-menu` 里多一层 `.rule-menu-level1`。

### 顶部总数卡

在线分流列表上方加一行六张卡，按类型给出规则总数与来源数（国内规则 1,413 / 海外规则 33 / GeoIP CN 23,510 / GeoIP 非 CN 576,754 / Geosite CN 440,795 / Geosite 非 CN 82,276）。点任意一张卡会展开该组并滚动过去。

### S1 · 在线分流按类型折叠

列表视图改成六个分组，每组一行组头：组名、类型（域名规则 / IP 段）、来源数、规则总数、组级「全部更新」。默认展开国内规则与海外规则两组，其余四组收起。

- 首屏从 46 行降到 10 行（国内 8 + 海外 2）。
- 组级「全部更新」只更新这一组，走的是原来的 `/plugins/{tag}/update-all`。
- 搜索与「国内解析 / 海外解析」筛选照旧生效，被筛空的组会整组隐藏。
- 顺手去掉重复的「类型」列（组头已经写了），把「异常」徽章挪到名称后面；格式、更新时间不再折行。
- 列表视图改成本页默认（「分组卡片」仍可在右上角切换，选择会按浏览器记住）。

### 修掉的两个回归

- **名单管理一度只剩原文**：站点用 `.rule-menu button.active` 取「当前名单」，两级化之后第一个 active 变成了分组按钮（没有 `data-rule-tag`），取不到名单 → 名单工作台（表格/原文切换、搜索、新增、全选、导出）整个不挂载。改成按 `.rule-menu [data-rule-tag].active` 取；顺带修好手机端「名单类别」下拉——它原来遍历 `.rule-menu button` 建选项，遇到分组按钮会因为找不到 `<span>` 直接抛错，现在改成读页面写出的完整清单并按分组输出 `optgroup`。
- **在线分流少了总数**：见上面的总数卡。

## 验证

- `npm run check` 全绿：21 个测试文件 173 项单测、ESLint、`tsc --noEmit`、构建一致性、字体子集。
- 生产机（Alpine 3.23 / 192.168.8.2）实机用无头浏览器点过：
  - 名单页签初始为「核心分流 / 白名单」，点「解析控制」后二级变 4 项、编辑区切到「强制 RealIP」，再点「重定向」编辑区跟着换。
  - 在线分流渲染出 6 个组：国内规则 8 个来源 / 1,413 条、海外规则 2 / 33、GeoIP CN 9 / 23,510、GeoIP 非 CN 18 / 576,754、Geosite CN 5 / 440,795、Geosite 非 CN 4 / 82,276；默认只展开前两组。

  - 名单管理：`#rv-root` 存在、工具栏按钮齐全，`.rule-textarea` 上 `data-original` 已写入；在线分流六张卡读数与接口一致。

## 升级说明

- **UI 更新包**：只替换界面资源，不动内核、配置、规则与上游，无需重启 DNS；安装后刷新页面即可。要求内核已是 **FJH7T**（安装脚本按 `backendVersion` 做同核心校验）。
- **完整包**：含 FJH7T 内核与干净的默认配置，用于全新安装或整机替换。
- 若浏览器里保存过「分组卡片」的排列偏好，升级后仍按保存的来；想用新的分组表，点右上角「表格列表」即可。
