# FJGOE / UI 2026.10.27.1

修复 UI 审查发现的 53 项问题（PR #9）：涵盖上游节点编辑保留全部未管理字段、分流与规则工作台修复、概览页状态与口径修正、字体子集补全与移动端触控/输入体验改进，以及基础通信错误处理与连接心跳加固。

- **上游编辑保留未管理字段（高危 `E-01`）**：编辑上游 DNS 节点时不再清除 `bootstrap`、`enable_http3`、`enable_pipeline`、`account_id`、`access_key_id`、`access_key_secret`、`server_addr`、`ecs_client_ip`、`ecs_client_mask`、`ecs_mask` 等表单未管理字段，同时缓存弹窗内已输入的 ECS，避免切换分组或编辑保存时丢失原有凭证与高级参数。
- **规则与代理配置修复（`D1`–`D18`）**：手写裸 `# 域名/IP/网段` 行判为名单说明（`doc`）而非分组标题或规则备注，避免被误认领或误删；规则编辑补齐查重逻辑，批量删除连带清理附属 `# 备注` 行；在线分流规则改名前拦截重名；保存成功但未识别格式时改走警告提示并正常刷新列表与清理旧配置。
- **概览页状态与口径修正（`C-01`/`C-02`/`C-04`–`C-08`/`C-16`）**：客户端分流模式切换增加在途按钮禁用、代次号防乱序与回滚前真实状态回读；百分比指标钳制在 `0–100%`；开关或指标读取失败时展示「未知」状态并禁用对应切换，避免误显示为关闭；处理结果抽屉百分比统一以当前抽屉合计为分母。
- **日志、管理与上游细节修复（`E-02`–`E-17`）**：复用本页 `/metrics` 请求；清空分流数据按项汇总失败明细；补齐缓存清空/查看、分流刷新触发/取消、重启服务等写操作的异常捕获提示；功能开关互斥切换第二步失败时自动回滚第一步。
- **字体子集、移动端与连接心跳（`F1`–`F13`、`B1`/`B3`/`B5`）**：从当前前端源码重新提取全部汉字生成 Noto Sans SC / Noto Serif SC 子集（覆盖全部 877 个源码汉字）并新增 `check:fonts` 校验；修复移动端 `≤600px` 输入框字号不足 `16px` 的级联覆盖问题，触控目标高度统一为 `44px`；补齐 `prefers-reduced-transparency` 降级样式；新增 30 秒后台连接状态心跳。
- **基础层与对话框改进（`A-M1`–`A-M3`、`A-L1`/`A-L2`/`A-L10`/`A-L14`）**：网关返回 HTML 错误页时回退为 HTTP 状态码；批量规则更新传输失败返回部分结果并归入「待确认」；弹窗支持重入守卫与自动聚焦首个控件；常驻错误通知上限控制为 3 条；静默刷新完成后立即清除页面 `minHeight`。
- 仅改动前端界面与构建校验脚本，DNS 内核、上游、规则、订阅与客户端别名均不受影响。

**升级说明**：
- 本次为纯 UI 更新，已安装 FJGOE 的设备直接使用网页一键升级或 `LocalDNS_UI_2026.10.27.1_Update.zip` 即可，**无需重启 DNS 内核**。
- 升级包内含逐文件 `MANIFEST.sha256`，`install-ui.sh` 会先校验再安装，并自动保留上一版 UI 目录与备份压缩包，失败可回退。
- 手动安装方式（以默认目录为例）：

  ```sh
  unzip LocalDNS_UI_2026.10.27.1_Update.zip -d ui-update
  cd ui-update && sh install-ui.sh /opt/localdns
  ```
