# FJGLI / UI 2026.10.22.1

本版适配 FJGLI 的新配置结构和管理接口，保留现有定制界面、DNS 趋势、共享设置及代理配置编辑器。

## 已有版本升级

**FJGAC / FJGIR 升级到 FJGLI 需要完整包迁移，不能只替换内核或 UI。**

- 先下载原 VM 的完整备份并核对 SHA-256；上游和手工规则必须保留，客户端别名与自定义订阅一并迁移。
- 完整包新增 `upgrade-localdns.py`：备份、准备、隔离验证、切换和恢复；原目录移至同级回退目录，新运行目录整体替换。
- 自动迁移别名文件名、缓存字段、150 MB 等原内存预算、日志容量与目录、功能开关和定时计划；保留 UI 个性化文件及兼容库。
- 旧在线来源由新内核重新编译，旧缓存、编译状态及查询历史不整目录恢复。
- 普通 UI 更新继续保留核心，跨核心包会在替换前停止并提示。保留旧核心可指定对应旧 Release。

步骤见 [完整更新指南](../FJGLI_UPGRADE.md#完整更新命令)。未知配置或冲突会停止迁移，备份和回退目录不会自动删除。

## 界面与发行包

- 统一适配查询日志、别名、手工名单、开关、缓存、广告订阅、分流订阅和刷新任务接口；继续识别旧核心。
- 客户端策略采用新版枚举，保留旧界面操作语义；失败的写请求不会换接口重复提交。
- 支持 MRS、MMDB、DB 来源格式显示，保留订阅更新长任务与结果待确认提示。
- 完整包使用清理后的 FJGLI 默认运行结构，提供 amd64-v1、amd64-v3、arm64；一键安装默认 x86-64 v1。
- 配套 Mihomo / sing-box 配置服务继续使用 1.6.0。

验证范围和实机结果见 [验收记录](../validation/fjgli-upgrade-2026.10.22.md)。
