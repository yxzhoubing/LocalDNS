# FJH50 / UI 2026.10.29.9

UX 审查 P1 修复、全站确认框改造、趋势旧行迁移修正，并新增可选的 Mihomo 回流规则守护服务。

## 确认框

- 原生 `confirm()` 全站替换为 `confirmDialog()`（19 处），返回 Promise、Esc 视为取消、`danger` 时默认聚焦「取消」。
- 确认框改用独立的 `#confirm-modal`，不再复用 `#modal`。此前若在已打开的弹窗内调用（审计控制的四个入口正是如此），确认框会覆盖该弹窗的内容，并在确认后把它一并关闭——请求照发，但保存提示、存储详情刷新与页面重渲染全部被跳过；「清空日志」同样不发提示、不刷新列表。
- 顺带修一处静默失败：审计控制的四个处理函数在 `await` 之后读取 `event.currentTarget`（此时已为 `null`），生产环境点击按钮没有任何反馈。

## 设备页

- `⋯` 菜单改为挂到 `body` 的 fixed 定位，视口钳制、下方空间不足时向上翻，滚动或缩放即关闭；末几行不再被表格的 `overflow: hidden` 裁掉。
- 过滤 / 排序 / 关键词状态提到模块级，写操作后的静默重渲染不再重置筛选；搜索框清空后自动恢复全量。
- 名单加载失败时，行内的 FakeIP / RealIP 与停用 / 启用按钮置灰并给出 `title`，不再点了没反应。
- 筛选无结果时显示空态文案与「清除筛选」，与真正的空列表区分开。

## 概览

- 版本串、启动时间、运行时长、平均耗时各只保留一处；去掉「已连接」徽章；标题「运行概览」改为「概览」。
- 第三条控制栏由「运行中 · 时长」改为「功能开关」，AdGuard 开关语义归位。
- AdGuard 未启用时 KPI 卡折叠为「未启用」小卡，点击跳转分流页开启。
- 结果分布只有一个类别时隐藏圆环改为文字，不再画出无意义的整圆。

## 解析页

- `≤600px` 时 `.workspace-upstream-group .table-wrap` 恢复横向滚动，表格不再被压扁。作用域限定在该分组，未改动全局。

## 术语

- 「分流 / 解析去向 / 解析路径」统一为「分流结果」，「国外」统一为「海外」，乐观过期表述统一。

## 趋势

- 旧行迁移改为清空 `upstreams`：加载行从不持久化 `latency`，原「`latencyNow` 为空且 `latency` 非空」的过滤恒为空，迁移从未执行；而且 `record()` 由相邻行 `upstreams` 差值重算区间延迟，置空 `latency` 也不起作用。现在 p50 之前的历史行不再补出误导性的区间均值，请求量与命中率不受影响。

## 回流规则守护（可选）

- 新增 `services/mihomo-return-guard/`：校验既有的 Mihomo 回流 / 旁路防火墙与策略路由，缺失时只调用既有脚本修复，绝不自建拦截链。`--check` 只读，`--ensure` / `--watch` 经共享锁串行。13 项单测覆盖健康不改动、核心链未就绪不重建、只修复对应协议族等回归。
- 该服务是仓库内的可选组件，**不在本发行包内、也不会自动安装**；需要时按 `services/mihomo-return-guard/README.md` 手动部署。
