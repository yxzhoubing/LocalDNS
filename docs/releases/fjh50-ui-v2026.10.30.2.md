# FJH50 / UI 2026.10.30.2

恢复概览趋势卡的标题与设备页的策略名称，并把概览渲染增强链纳入测试。

## 问题

概览页「响应延迟与解析异常」这张卡一直不显示标题，时间范围按钮顶在左上角。原因是 `frontend/src/features/shell/interface.js` 用「头部的最后一个子元素」来定位时间范围控件：

```js
setHTML($('.gc-title', head), '响应延迟与解析异常');
const range = head.lastElementChild;   // 实际拿到的是标题本身
range.className = 'console-range';     // 标题的 class 被覆盖
setHTML(range, ...4 个按钮...);        // 标题文字被按钮替换
```

而这张卡的 `.gc-head` 里只有 `.gc-title` 一个子元素，于是标题被就地改名成范围容器。`.gc-head` 本身是 `display:flex; justify-content:space-between`，设计上就是「标题在左、控件在右」，所以正确的形态应该两样都在。

## 修复

不再劫持标题，改为复用或新建独立容器：

```js
setHTML($('.gc-title', head), '响应延迟与解析异常');
let range = $('.console-range', head);
if (!range) { range = document.createElement('div'); head.append(range); }
range.className = 'console-range';
```

复用而不是每次新建，重复渲染不会叠加出多个范围控件。
