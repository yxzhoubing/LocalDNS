# FJH21 / UI 2026.10.28.2

接入新内核 **FJH21**（来自 `LocalDNS_FJH21.zip`，包内 `localdns/bin/localdns` 与 `LocalDNS_FJH21_Binaries/localdns-amd64-v3` 为同一份 `amd64-v3` 程序，SHA-256 `d251c4fb…a86596`），并把内核新增的两组设置接入界面：**查询日志存盘开关**与**缓存记录数 / 保留时间 / 写盘间隔**。

> 更早一次发来的 `LocalDNS_FJH1Z.zip` 中，运行目录 `localdns/bin/localdns` 与本次 `LocalDNS_FJH21.zip` 的对应文件**逐字节相同**，只有 `LocalDNS_FJH1Z_Binaries/` 下的四份程序是较旧的 `FJH1Z`（缺少 `/api/v1/cache/limits`）。部署一直使用运行目录内的 `FJH21` 程序，因此两次包得到的运行内核一致；`LocalDNS_FJH21.zip` 的 `cache.json`、`generated.json` 默认值（50 万条 / 600 秒与 3600 秒）也与现网保留的设置相同。

- **查询日志存盘开关**：「查询日志 → 审计控制」新增「记录存盘」开关。内核在 `/api/v1/querylog/settings` 中返回 `persist`，切换后立即生效：关闭时只保留内存中的最新记录，磁盘占用保持 0；开启后查询记录压缩写入日志目录。新装默认不存盘（`config/settings/querylog.json` 中 `persist: false`）。
- **缓存参数编辑**：「系统管理 → 缓存管理」新增「缓存参数」，可分别调整全部缓存、国内缓存、国外缓存与国外 ECS 缓存的**最大记录数**、**过期保留**（小时）与**写盘间隔**（分钟）。保存通过 `POST /api/v1/cache/limits` 一次性提交四个缓存池，界面按内核返回的 `limits` 做范围校验，并用 `running` 与当前值比对标记「待重启」；内核返回 `restart_needed` 时卡片显示「参数待重启」徽章。
- **旧内核兼容**：仅当内核返回 `limits`（FJH21 起）时才显示「缓存参数」；`persist` 缺失时隐藏存盘开关。FJGOE 及更早内核的页面表现不变。
- **验证**：新增 `frontend/tests/cache-settings.test.ts`（契约解析、单位换算、范围校验、弹窗表单与读取器一致性）并扩充 `audit.test.ts`（存盘开关状态、保存、失败回滚、旧内核隐藏），`npm run check` 共 159 项测试通过；隔离实例与生产环境均完成浏览器回归（1440 / 390、深浅主题、六个路由无报错、无横向溢出）。

## 内核行为说明

- `persist` 会写回 `config/settings/querylog.json`：关闭保存为 `"persist": false`，开启是默认值、文件中省略该键，重启后按文件恢复。实测「开 → 关 → 重启」后仍为关闭。
- 缓存记录数在缓存启动时分配，修改后需重启内核生效；过期保留与写盘间隔保存即生效。
- 新版在线规则与手工名单沿用原文件，编译结果由内核重新生成；`cache/`、`generated/` 与历史查询日志不迁移，学习类列表（RealIP / FakeIP / NODATA）从零重新积累。

## 升级说明

本次为跨内核升级，必须使用完整包替换运行目录，不能只替换 `bin/localdns`：

1. 备份 `config/upstreams/`、`rules/manual/`、`config/settings/client_aliases.json`、`config/subscriptions/` 与 `config/settings/*.json`。
2. 停止服务，清空 `/opt/localdns` 后放入新版本目录。
3. 回填上述配置与 `rules/online/`，保留 `bin/glibc-shim.so`、`bin/configure-ui.py`、`bin/ui-updater/`、`.ui-updater/`、`ui/config.js` 与 `ui/custom/`。
4. 启动服务，核对 DNS、上游、名单、别名、订阅与规则数量。

已在 Alpine x86-64（YoPilot，单核）实测：UDP/TCP 解析正常，四组上游、11 个手工名单、41 条客户端别名、6 组订阅与全部规则数量与升级前一致。
