# FJH21 / UI 2026.10.29.2

本次更新完整对齐概览演进设计方案，补齐首屏链路健康状态横条、响应延迟与解析异常双线峰值趋势图及五阶段拓扑活跃路径聚焦，并在「设备」页面新增单机 `FakeIP / RealIP` 策略胶囊直切能力。

- **「设备」页单机 `FakeIP / RealIP` 直接切换（`#/devices`）**：
  - 受控设备列表每行新增 `[ FakeIP | RealIP ]` 双态胶囊开关，直接切换单台设备的实际解析策略（`✓ FakeIP 科学分流` / `→ RealIP 真实解析`），无需将设备移出列表即可在 `指定 FakeIP` 或 `指定 RealIP` 模式下为单台设备配置分流或直连；
  - 右侧「局域网活跃设备」列表按钮随当前全局策略动态联动为 `+ 加入 FakeIP 名单` / `+ 加入 RealIP 名单`。
- **首屏服务摘要与「✓ 链路健康」状态横条**：
  - 将启动时间合并至内核版本副标题行，顶部 4 项运行体征补齐为「运行时长 / 上游 DNS 健康 (`X/Y 启用在线`) / 进程 CPU（首帧回退运行均值消除常驻空值）/ 内存占用」；
  - 新增「`✓ 链路健康`」诊断状态横条，实时展示国内并发竞速均值与主力节点采纳率、累计查询 `SERVFAIL` 与慢查询(`>100ms`)组数，并提供 `高亮当前主流量路径` 按钮联动五阶段拓扑锁定；
  - 6 张独立 KPI 卡片副标题同步补齐国内池/乐观过期命中率、当前客户端分流模式、黑名单生效条数及上游竞速均值/P95 耗时。
- **「响应延迟与解析异常」趋势视图与拓扑「仅看活跃路径」**：
  - 趋势卡升级为「响应延迟与解析异常」，默认展示 `延迟与异常 (默认视图)`（含整体平均响应、上游竞速均值、P95/最大耗时、失败与慢查询 4 项摘要及上游实线+含缓存虚线+慢查询峰值柱标图），并保留 `请求量与缓存命中率 / 缓存命中率 / 平均延迟` 指标切换；
  - 五阶段解析路径工具栏新增 `仅看活跃路径` 开关，一键弱化 0 流量空闲分支；
  - 移除「解析」导航项右侧常驻蓝点，保持 7 项一级导航视觉干净统一。
- **验证**：`npm run check`（构建、TS 类型检查、161 项单元测试、ESLint 零警告、构建指纹校验、Noto SC 字体子集覆盖校验）及 5 个工具链 Python 测试模块全部通过。

## 升级说明

本次仅更新前端界面与安装脚本，**不涉及 DNS 内核、配置、规则与上游**：

1. 已在 FJH21 上的设备可直接通过网页端「版本与更新」在线升级，或运行更新包中的 `install-ui.sh`；无需重启 DNS。
2. FJGOE 及更早内核请勿直接升级本界面包，仍按 [更新指南](../FJGLI_UPGRADE.md) 使用完整包迁移。
