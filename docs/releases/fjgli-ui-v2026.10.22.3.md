# FJGLI / UI 2026.10.22.3

修复管理操作复核中发现的在线分流保存误报。

- FJGLI 成功更新可能只返回 `changed: true/false`，没有格式和数量。界面现在正确接受成功结果，支持新增、编辑、启停和未变化来源。
- 没有格式和数量时明确显示未记录，不再误报“尚未识别”或 0 条规则。旧核心的数据集选择和失败处理继续保留。
- 广告订阅编辑和启停共用保存逻辑，剔除只读行报告，修正编译路径说明。
- 直接进入 DNS 等页面时正确显示 FJGLI 核心名称；构建验证检查初始标签与版本文件一致。

**已安装 FJGLI 的设备只需更新 UI，无需更换核心或重启 DNS。** 从 FJGAC / FJGIR 跨核心升级仍使用 [完整更新指南](../FJGLI_UPGRADE.md)。配置服务仍为 1.6.0。

验证：120 项前端测试；68 项真实 FJGLI 接口检查，涵盖四组上游、11 类名单、客户端别名、八个开关、日志、缓存、刷新任务、五类分流、广告订阅、真实 DNS 应答与重启保留。详情见 [复核记录](../validation/fjgli-management-2026.10.22.md)。
