# FJH7T / UI 2026.10.31.2

名单管理采用选定的方案 2「左起同轴联动条」，让分组、名单和用途之间的关系更直观。

## 改动

- 核心分流 / 解析控制 / PCDN 抑制靠左排列，箭头后紧接当前分组的名单胶囊；用途说明位于右侧。
- 名单使用语义色点和实际启用规则数量；数量排除空行、注释和禁用规则，未保存草稿不会改变已保存数量。仅补读当前分组的名单，切换视图时取消旧请求。
- 卡头收紧为标题、草稿提示与设备入口，工作台继续提供搜索、增删、列表 / 原文切换、导出和保存。
- 手机端分组与名单自然换行，隐藏可选数量与导航用途说明，编辑区仍显示完整用途。移除旧手机下拉和等待胶囊出现的监听逻辑，统一直接切换。
- 保留切换时的草稿恢复、未完成编辑保护、慢响应与连续选择处理。

## 验证

- `npm run --prefix frontend check`：构建、类型检查、22 个测试文件 / 180 项测试、lint、构建一致性及字体覆盖检查通过。
- 7 项名单集成测试覆盖同栏选择、跨组选择、连续选择、8.5 秒慢响应、草稿恢复、离页返回和真实数量；使用真实渲染、工作台与 API 客户端，仅模拟网络和时间。
- 本地只读预览检查桌面与 390px 手机布局，确认编辑工作台挂载和实际分组切换正常。
