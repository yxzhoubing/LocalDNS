# FJH50 / UI 2026.10.29.7

修复 2026.10.29.6 发行后发现的问题：中文字体子集缺字、安装说明版本过期、Windows 打包可能产生 CRLF；并带上趋势卡延迟曲线改用上游 p50 的修复。

> **发行要求**：本版须同时发布 **完整包** `LocalDNS_FJH50_UI_2026.10.29.7_Full.zip`、UI 升级包与 `SHA256SUMS.txt`。一键安装器（`tools/install_localdns.py`）新装时要求最新 Release 中恰好有一个 `*_Full.zip`，只发 UI 升级包会让新装失败。完整包以已发布的 `LocalDNS_FJH50_UI_2026.10.29.6_Full.zip`（SHA-256 `26dd546a…b7f91e603bb`）为基础，用 `python tools/package_ui.py --full-base <该文件> --base-sha256 26dd546a8401e688c4adbb6b23ad19c52b871cc79d1ef27dcfa00b7f91e603bb` 生成，内核与默认配置原样沿用。

## 字体子集

- 2026.10.29.6 新增的源码文字里有 4 个汉字不在 Noto Serif SC / Noto Sans SC 子集内：热 `U+70ED`、窄 `U+7A84`、竖 `U+7AD6`、轴 `U+8F74`（「左轴每秒请求数 · 右轴主缓存命中率」等），`npm run check:fonts` 失败，这些字会回退到系统字体。本版趋势卡改动又新增仪 `U+4EEA`、抓 `U+6293`，一并补齐。
- 两个子集已按 `manifest.json` 记录的来源（google/fonts `NotoSerifSC[wght].ttf` / `NotoSansSC[wght].ttf`，版本 2.003 / 2.004）重新生成：保留完整 `wght` 可变轴与全部 OpenType 特性，覆盖原有全部字符并补上缺字，汉字 888 → 894 个；`fonts.css` 两段 `unicode-range` 只新增这 6 个码位，`manifest.json` 的大小与 SHA-256 同步更新。
- 新增 `tools/subset_noto_fonts.py`，把重生成流程固定下来（`pip install fonttools brotli` 后运行 `python tools/subset_noto_fonts.py --source-dir <源字体目录>`），以后 `check:fonts` 报缺字时直接重跑即可。

## 趋势卡

- 延迟曲线改用各上游 `quantile=0.5` 的计数加权值（上游 p50），每次抓取都更新；原先的区间平均延迟只在采样窗口内有上游应答时才产生，缓存命中率高的机器一小时只有几个点。summary / aggregate 对延迟改为等权平均，纵轴标注改为「上游 p50」。

## 文档

- `INSTALL.md` 的「当前发行版本」仍停在 `FJGOE / UI 2026.10.23.2`，下载表、Release 链接、二进制目录名也都是 FJGOE；统一改为 FJH50 / UI 2026.10.29.7。
- `README.md` 手动安装一节的 Release 链接从 `fjh21-ui-v2026.10.28.2` 改为本版。

## 换行规范

- `.gitattributes` 改为 `* text=auto eol=lf`：无论 `core.autocrlf` 如何设置，工作区里的源码都是 LF，Windows 上构建和打包不会再把 CRLF 带进 CSS / JS 和发行包。
- 补齐图片、字体、压缩包等二进制标记；`_src/ui/** -text`（保持已验证 UI 字节不变）保留。
- 用 `git add --renormalize .` 核对：除 `.gitattributes` 本身外没有任何文件被重写。
- 已发布的 2026.10.29.6 完整包里 `localdns/ui/index.html`、`localdns/ui/assets/index-*.css` 与 `docs/validation/frontend-refactor-2026.10.19.8.md` 带 CRLF；本版在 LF 工作区重建后，这些文件均为 LF（`_src/ui/` 内按原字节保留的 `manifest.json` 与两份 OFL 许可除外）。

## 打包工具
