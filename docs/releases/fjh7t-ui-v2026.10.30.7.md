# FJH7T / UI 2026.10.30.7

名单管理的分组切换从卡片内部搬到卡片头（方案 D）：卡片头左侧是「名单管理」标题与提示，右侧是核心分流 / 解析控制 / PCDN 抑制的分段控件；卡片内部只剩一行名单胶囊。四个候选版式（A 现状 / B 下拉加页签 / C 两行拉开 / D 组在卡头）做成可点页面供挑选后，按选定的 D 落地。

## 背景

两级页签（2026.10.30.6 的 T1）解决了组名与名单同层的问题，但卡片里叠了两层控件——上面一条分段控件、下面一排描边胶囊，两行只隔 10px，两种控件长得又像，看起来糊成一坨。

## 改动

### 分组切换上移到卡头

- **卡头**：与「广告拦截规则」「在线分流规则」两张卡同构的 `card-header`——左侧图标 + 「名单管理」标题 + 提示「本地名单 · 启停与编辑先保留为草稿」，右侧是三个分组的分段控件，自带底部分隔线。
- **卡内只剩一行**：`.rule-menu` 里只留该组的名单胶囊；选组（卡头）与选名单（胶囊）从此不在同一块区域，视觉上不会再粘在一起。
- 窄屏（≤600px）卡头说明行收起，标题与分段控件保持一行；「名单类别」下拉照旧用于切名单。
- 名单说明行（工作台标题下的灰字）不再重复「先保留为草稿」，只显示名单本身的用途说明。

### 顺带加固

- `toolbar.js` / `workbench.js` 里取「当前名单」的两处选择器改为 `.rule-menu [data-rule-tag].active`，与 2026.10.30.6 对 `interface.js` 的修法一致——分组按钮也带 `.active`，以前这两处可能取到分组按钮而拿不到名单。

## 位置

| 位置 | 改动 |
