# 本机 UI 修复版 2026.10.19.3-local

本版依据 `docs/validation/ui-audit-2026.10.19.2.md` 的十项问题实施，沿用三栏外观面板、双皮肤和概览底部 5+7 布局。

- 手机排行使用专用表格，默认五条，保留“更多”入口；修复通用表格样式反复覆盖的问题。
- 提亮羊皮纸深色缓存标签与辅助文字。
- 恢复统一页面标题；重启服务入口放入系统管理底部的 DNS 服务区。
- 统一同级板块 16px 间距、卡片桌面 20px / 手机 16px 内边距。
- 系统管理底部卡片按内容自然高度显示。
- 手机缓存卡改为单列，指标 390px 四列 / 320px 两列；移除模板与布局脚本中的内联强制样式。
- 扩大本次审查涉及的缓存、排行、规则工具与复选框、代理入口等触摸区域。
- 手机日志默认 25 条，常用筛选与显示设置默认折叠，记录使用三行紧凑布局，增加顶部分页。
- 修复被旧记录卡样式覆盖的日志网格；保留列表切换和详情入口。
- 调整手机功能标签字号、域名省略及配置路径换行；完整内容仍可通过提示与详情查看。
- 手机连接状态在品牌图标角落显示，状态变化可被辅助技术读取。

仅更新本机 UI，发布渠道为 `local`，未同步 GitHub。
