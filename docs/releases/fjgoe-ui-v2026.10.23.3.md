# FJGOE / UI 2026.10.23.3

修复运行概览「运行时长」在长时间运行后只按小时累计的问题，满 24 小时进位为天。

- **运行时长按天显示**：运行概览顶部的「运行时长」原先只拆到小时与分钟，实例连续运行一天以上后会显示成「46 小时 49 分钟」这类读数。现在按「天 / 小时 / 分钟 / 秒」分档并保留两段，同一时刻显示为「1 天 22 小时」，与概览下方「在线 X天 X小时」的口径一致。
- **回归测试**：新增 `frontend/tests/uptime-format.test.ts`，覆盖 23 小时 59 分、整 24 小时、跨天、90 小时、不足 1 分钟及非法输入，并断言小时数永不超过 24。
- 仅改动前端格式化函数，DNS 内核、上游、规则、订阅与客户端别名均不受影响。

**升级说明**：
- 本次为纯 UI 更新，已安装 FJGOE 的设备直接使用 `LocalDNS_UI_2026.10.23.3_Update.zip` 即可，**无需重启 DNS 内核**。
- 升级包内含逐文件 `MANIFEST.sha256`，`install-ui.sh` 会先校验再安装，并自动保留上一版 UI 目录与备份压缩包，失败可回退。
- 安装方式（以默认目录为例）：

  ```sh
  unzip LocalDNS_UI_2026.10.23.3_Update.zip -d ui-update
  cd ui-update && sh install-ui.sh /opt/localdns
  ```
