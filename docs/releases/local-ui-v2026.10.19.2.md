# UI 2026.10.19.2 本地测试版

基于 GitHub 正式版 FJGAC / UI 2026.10.18.19。

- 外观面板采用“主题背景 / 材质与布局 / 品牌与字体”三栏胶囊，支持方向键切换。
- 壁纸 URL 与应用按钮、滑块与数值、字体标签与下拉框同行显示；保留全部既有设置、上传与保存行为。
- 概览底部固定使用左五右七布局：四个缓存池以 2×2 卡片显示，右侧为紧凑慢查询表。两侧按内容自然撑高，取消方案对比栏及强制等高留白。
- 小屏幕转为上下排列；长慢查询列表使用有界滚动区域，保留 5 / 10 / 20 条切换和详情分页。

只部署本地 UI，不发布 GitHub。
