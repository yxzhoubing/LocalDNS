# UI 2026.10.19.1 本地测试版

基于 GitHub 正式版 FJGAC / UI 2026.10.18.19，仅用于本地部署验证。

- 查询处理结果展示前五类及“其他”，使用中文名称和按分类固定的颜色；可展开全部分类并筛选对应查询日志。
- 明确审计日志统计范围与最终处理结果口径，保留原始标签供排查。
- 慢查询改为独立整行表格，默认十条，可切换五、十或二十条并记住选择；显示序号、域名、查询类型、客户端及最大耗时。
- 四个真实缓存池补充查询数、命中数和当前条目数，并明确缓存指标与审计日志的统计周期不同。
- 顶栏新增 UI 版本与更新入口，自动读取 GitHub 最新正式版，缓存六小时，支持手动检查、失败重试和查看发布说明。当前本地版以基准正式版判断是否有后续更新。

本次部署只更新 UI 静态文件。
