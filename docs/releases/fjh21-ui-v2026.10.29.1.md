# FJH21 / UI 2026.10.29.1

本次更新重构控制台一级导航结构，新增独立「设备」页面聚合客户端分流策略与设备别名管理，并对运行概览、分流工作台、顶部搜索栏及侧栏状态卡做全面精简与死代码清理。

- **二字扁平导航（7 项单源头）**：侧边栏、折叠态、顶部导航、移动端底部栏与全局搜索页面直达统一以 `routes.js` 的 `routeDefs` 为唯一数据源，收敛为「概览 / 日志 / 解析 / 分流 / 设备 / 代理 / 系统」7 个二字一级入口，移除原有的分组小标题与跨多处硬编码。
- **新增「设备」一级页面（`#/devices`）**：将原先分散在概览/系统管理（`switch2` / `switch12` 客户端策略）、分流名单（`/plugins/client_ip` 受控设备）与查询日志弹窗（`/plugins/client_name` 设备别名）的三套客户端能力同屏整合为双栏卡片：
  - 左卡「客户端分流模式与受控设备名单」：支持 `全员分流 / 指定 FakeIP / 指定 RealIP` 串行切换与回滚保护，同屏管理受控客户端 IP / CIDR 的单条启停、移除、新增、原文批量编辑与导出；
  - 右卡「局域网活跃设备与别名映射」：聚合最近活跃查询来源与已保存别名，支持一键加入受控名单、点击别名快捷编辑、点击 IP 直达查询日志。
- **分流工作台分组排版（`#/rules`）**：随 `客户端 IP` 移至「设备」页，将其余 10 个名单按「核心分流（白名单 / 黑名单 / 灰名单）」「解析控制（强制 RealIP / DDNS 域名 / 直连 IP / 重定向）」「PCDN 抑制（PCDN 域名 / IPv4 正则 / IPv6 正则）」三组排布，并在胶囊下方展示当前选中名单的一句话说明与「设备」页快捷入口。
- **运行概览与壳层细节打磨**：
  - 侧栏底部状态区采用紧凑单行胶囊设计（状态绿点 + 在线状态/地址 + 右侧 28×28 琥珀色重启图标按钮）；
  - 顶栏全局搜索框移除浅色玻璃主题下的白色内胆，保持毛玻璃通透感，支持输入域名、客户端 IP 或页面名称回车直达；
  - DNS 趋势图时间跨度扩充为 `15 分钟 / 1 小时 / 24 小时 / 7 天`（本地采样保留上限同步扩展至 7 天）；
  - 移除运行概览卡片与排行榜底部重复的「当前审计保留记录 / 统计口径」说明文字，「活跃客户端」与「高频查询域名」保持左右独立双卡片。
- **旧版安装脚本护栏补齐**：包含 `tools/install-ui.sh` 的 `FJH21` 同核心校验护栏。
- **验证**：`npm run check`（构建、TS 类型检查、161 项单元测试、ESLint 零警告、构建指纹校验、Noto SC 字体子集覆盖校验）及 5 个工具链 Python 测试模块全部通过。

## 升级说明

本次仅更新前端界面与安装脚本，**不涉及 DNS 内核、配置、规则与上游**：

1. 已在 FJH21 上的设备可直接通过网页端「版本与更新」在线升级，或运行更新包中的 `install-ui.sh`；无需重启 DNS。
2. FJGOE 及更早内核请勿直接升级本界面包，仍按 [更新指南](../FJGLI_UPGRADE.md) 使用完整包迁移。
