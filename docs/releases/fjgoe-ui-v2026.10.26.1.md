# FJGOE / UI 2026.10.26.1

界面快速改进与无障碍优化：移除未使用的 Chart.js、提高玻璃面板对比度下限、静默刷新保留焦点、统一焦点环，并让错误通知常驻、路由切换可被读屏感知；同时修复浏览器验证脚本以对齐正式版 FJGOE 后端。

- **移除未使用的 Chart.js**：概览趋势图早已改为自绘 SVG，`index.html` 中同步阻塞加载的 `chart.umd.min.js`（约 205 KB）及无调用方的图表适配代码、vendor 文件与对应许可一并删除，首屏不再被这段脚本阻塞。
- **玻璃面板对比度下限**：「面板遮盖度」默认值由 48 调整为 55，滑块下限提高到 55；「背景暗化」下限提高到 15。旧版保存的低于下限的数值读取时自动钳制并回写；玻璃表面上的说明 / 帮助正文改用更高对比度的文字色，亮色壁纸下也能看清。
- **静默刷新保留焦点**：30 秒自动刷新重绘页面后，键盘焦点会恢复到原来的控件，不再跳回页面开头；键盘焦点停在主区域控件上或鼠标悬停拓扑图时暂缓自动刷新。
- **统一焦点环**：全站只保留一条 `:focus-visible` 焦点环规则（2px，偏移 2px），去掉各处颜色不一、互相覆盖的 `!important` 声明。
- **错误通知常驻**：错误通知不再 3.9 秒后自动消失，提供「关闭通知」按钮并使用 `role="alert"`；其余通知使用 `role="status"`，鼠标悬停或键盘聚焦时暂停计时。
- **路由切换可感知**：切换页面后焦点移到页面标题（h1），浏览器标签标题更新为「页面名 · 应用名」，应用名跟随「名称与 Logo」自定义；首屏加载不抢焦点。
- **浏览器验证脚本修复（PR #8）**：`verify_frontend_build`、`verify_frontend_routes`、`verify_frontend_matrix` 与 `verify_shared_ui` 的夹具对齐正式版 FJGOE 后端（共用 `tools/verify_support.cjs`），并新增可选环境变量 `LOCALDNS_BROWSER_PATH`，可指向本机 Chromium 等浏览器（默认仍使用 Edge）。
- 仅改动前端界面与验证工具，DNS 内核、上游、规则、订阅与客户端别名均不受影响。

**升级说明**：
- 本次为纯 UI 更新，已安装 FJGOE 的设备直接使用 `LocalDNS_UI_2026.10.26.1_Update.zip` 即可，**无需重启 DNS 内核**。
- 升级包内含逐文件 `MANIFEST.sha256`，`install-ui.sh` 会先校验再安装，并自动保留上一版 UI 目录与备份压缩包，失败可回退。
- 安装方式（以默认目录为例）：

  ```sh
  unzip LocalDNS_UI_2026.10.26.1_Update.zip -d ui-update
  cd ui-update && sh install-ui.sh /opt/localdns
  ```
