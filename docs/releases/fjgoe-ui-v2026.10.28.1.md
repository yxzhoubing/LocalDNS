# FJGOE / UI 2026.10.28.1

侧边栏底部状态区版式修复（PR #10）：此前状态区为一行三列，196px 宽侧边栏下重启按钮占约 80px 不让位，名字与面板地址被截成省略号；现改为上下两行，按钮独占一行满宽，地址可换行显示。

- **状态区改为上下两行**：第一行显示绿点、名字与地址，第二行重启内核按钮 `grid-column: 1 / -1`、宽 100%、最小高 36px，左右内边距由 2px 放到 8px；仅改动 `frontend/src/styles/features/shell.css` 3 行，HTML 结构、管理页重启按钮、按钮颜色与点击逻辑均未动。
- **地址不再截断**：地址行由不换行加省略改为可换行不断词，`http://10.0.0.x:18082` 这类地址在 196px 侧边栏下可完整显示；172px 窄侧边栏下超长地址换两行而非截断。
- **其他模式不受影响**：折叠态仍为 34px 图标按钮，顶部导航仍隐藏底部区，两处均由特异性更高的规则优先，版式测试 14 项全过。
- 仅改动前端界面样式，DNS 内核、上游、规则、订阅与客户端别名均不受影响。

**升级说明**：
- 本次为纯 UI 更新，已安装 FJGOE 的设备直接使用网页一键升级或 `LocalDNS_UI_2026.10.28.1_Update.zip` 即可，**无需重启 DNS 内核**。
- 升级包内含逐文件 `MANIFEST.sha256`，`install-ui.sh` 会先校验再安装，并自动保留上一版 UI 目录与备份压缩包，失败可回退。
- 手动安装方式（以默认目录为例）：

  ```sh
  unzip LocalDNS_UI_2026.10.28.1_Update.zip -d ui-update
  cd ui-update && sh install-ui.sh /opt/localdns
  ```
