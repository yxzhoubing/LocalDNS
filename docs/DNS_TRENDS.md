# DNS 趋势

默认显示最近 1 小时，可选 15 分钟、1 小时、6 小时、24 小时。每次显示一个指标，点击对应按钮切换；悬停、手机点选或聚焦图表后按左右方向键查看数据，Home / End 跳到首尾，Escape 关闭提示。

## 三个指标

| 指标 | 计算方式 | 单位 |
|---|---|---|
| QPS | 累计 DNS 请求数的增量 ÷ 实际采样秒数 | QPS |
| 缓存命中率 | `cache_main` 命中数增量 ÷ 查询数增量 | % |
| 平均延迟 | 所有已记录上游响应的耗时增量 ÷ 响应数增量 | ms |

延迟仅代表上游响应，不包含缓存命中请求；与运行概览中基于保留日志的总体平均响应口径不同。未发生缓存查询或上游响应时，该指标没有有效值，显示空缺，不画成 0。没有能区分 SERVFAIL 的可靠计数，因此没有加入 SERVFAIL 曲线。

区间均值分别按有效秒数、缓存查询数和上游响应数加权。峰值来自原始采样区间；长时间范围汇总为最多约 480 个绘图点，细竖线标记汇总区间的原始峰值，断采处断开。图表横轴展示所选范围内实际有采样的时间跨度，不推算尚未采到的时段。

## 24 小时本机历史

浏览器在概览可见时每 5 秒读取既有 `/metrics`，无需新增接口或服务器采样服务。IndexedDB 每次只写入一条原始计数快照，不反复写入整天记录；同一 API 地址每个 5 秒时段保留最新的一条，多标签页不会无限重复保存。

进入概览时立即开始读取指标，与其他概览内容和本机历史读取并行。首次基线约 2 秒后补采一次，之后仍每 5 秒更新；历史写入在后台执行，不阻塞实时请求。实际首次显示时间也取决于网络和页面加载速度。

- 数据库名为 `localdns-dns-trends`，按 DNS API 地址隔离历史；最近 24 小时约 17,280 条快照，过期数据在后续写入时清理。
- 刷新网页后恢复本浏览器已经保存的历史，默认范围仍为 1 小时；其他浏览器和设备没有这份本机历史。
- 核心重启、计数回退、上游计数集合改变或长期断采时建立新基线；不会清空之前的有效历史。
- 关闭网页、离开概览或后台休眠期间停止采样，回来后重新建立基线，不补零、不补造中间曲线。
- 浏览器禁止存储、空间不足或存储读取超时时明确提示，继续提供本次页面的临时采样；清除站点数据会删除历史。

仅保存统计计数、采样时间、核心启动标识与用于区分上游计数的标签，不保存 DNS 查询域名、客户端 IP 或日志正文。本功能不修改 DNS 核心、配置、规则或 9100 更新服务。
