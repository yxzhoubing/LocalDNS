# LocalDNS 功能与使用指南

适用源码版本：**后端 FJGIR / UI 2026.10.21.2**。

[返回首页](../README.md) · [产品图集](SCREENSHOTS.md) · [安装与更新](../INSTALL.md)

DNS 核心主要由**折腾日记交流群里的 R 大使用 Rust 编写**，**[yyhoworks](https://github.com/yyhoworks) 负责 UI 设计**。以下说明对应当前 UI 已有页面与交互；DNS 处理、配置保存和订阅更新由配套后端及插件执行。

## 运行概览

### 服务与关键指标

顶部展示服务在线状态、核心版本、启动时间、运行时长、**进程** CPU 与内存占用，以及六项 DNS 指标：

| 指标 | 用途 |
|---|---|
| 累计请求 | 查看当前运行数据中的 DNS 查询总量 |
| 缓存命中 | 查看缓存命中比例；核心缓存关闭时显示关闭状态 |
| 客户端数 | 了解请求来源设备数量 |
| 拦截请求 | 查看广告拦截统计 |
| 平均响应 | 查看 DNS 查询平均耗时 |
| 域名统计 | 了解当前统计的域名数量 |

### 趋势、分流与解析路径

- **DNS 趋势**：切换 QPS、主缓存命中率和上游平均延迟，每次显示一个指标与对应单位；默认 1 小时，可选 15 分钟 / 1 小时 / 6 小时 / 24 小时。概览可见时每 5 秒读取指标，本浏览器通过 IndexedDB 保存最近 24 小时原始采样，刷新后恢复；不同 DNS API 地址分别保存。长范围最多约 480 个汇总点，保留原始峰值，支持鼠标、触摸和方向键查看。关闭网页、切换页面和后台休眠期间不补造数据；存储不可用时明确提示并继续临时采样，不依赖 9100 服务。详见 [趋势说明](DNS_TRENDS.md)。
- **查询处理结果占比**：按后端 `domain_set` 统计当前保留日志的最终处理结果，展示前五类和“其他”，支持展开全部分类及日志筛选。缓存命中不展开原始国内 / 国外去向。
- **DNS 解析路径**：从客户端、引擎与多级缓存、分流规则到上游组和上游节点展示解析关系；支持分支 / 节点锁定、详情与相关查询。连线为关系示意。
- **请求排行**：在拓扑下方同时展示域名、客户端和最终解析去向排行，点击条目筛选相关日志；范围为当前审计保留记录，平均延时优先使用后端统计，缺失时按每项最近最多 1,000 条请求日志计算；超出范围标注样本数，结果缓存 60 秒，保留真实 0 ms。
- **缓存池与慢查询**：四个缓存池展示命中率、查询数、命中数与当前条目。慢查询支持 5 / 10 / 20 条、域名日志追溯及桌面卡内滚动，缓存运行指标与审计日志采用不同统计周期。
- **版本与更新**：顶栏展示当前 UI 版本，每六小时检查 GitHub 最新正式版，支持手动检查、失败重试和查看安装包。
- **外观三栏**：通过“主题背景 / 材质与布局 / 品牌与字体”胶囊分栏调整设置，保留既有皮肤、壁纸、字体和布局偏好。
- **快捷控制**：展开「快捷控制」，操作常用缓存、广告屏蔽与客户端分流功能。

## 卡片与列表排列

在线分流规则、广告订阅、DNS 上游、查询日志、缓存管理与功能开关都可通过板块标题旁的按钮切换卡片 / 列表。各板块分别记住选择，偏好仅保存在当前浏览器并按 API 地址隔离；切换时保留筛选、当前页和输入。手机选择列表后，可在宽表框内横向滚动。

## 查询日志与排障

1. 打开「查询日志」，输入域名或 IP；需要匹配完整值时勾选「精确匹配」。
2. 按请求类型、分流结果、响应码或客户端组合筛选，点击「查询」；搜索框也支持 Enter。
3. 点击记录的「详情」，查看请求来源、缓存记录、最终分流与应答组成的路径摘要，点击步骤查看已有依据，并可展开原始日志。

支持分页、常用筛选保存、条件标签移除、显示列偏好、暂停刷新和当前页 JSON 导出；筛选选项由后端现有记录提供。当前内核未提供完整逐步执行事件，不补造规则条目、具体上游、TTL 或分段耗时。

### 审计与客户端别名

- 「审计控制」可开启 / 关闭查询日志记录、调整最大记录容量（100–1,000,000 条）、清空日志。
- FJGIR 支持在同一弹窗设置日志存储目录。`logs` 基于 LocalDNS 安装目录，也可填写 `/var/log/localdns` 等服务器绝对路径；界面显示实际路径、内存和磁盘占用及条目数。
- 最新 2,000 条记录留在内存，其余压缩写入目录；重启服务后查询记录清空，目录设置保留。切换目录也会清空当前查询记录，旧压缩文件留在原目录，不自动迁移。
- 旧核心不支持此接口时显示升级提示；不可写路径或网络错误会显示失败并保留输入。
- 「客户端别名」可为已有客户端 IP 设置易读名称，便于在日志与概览中识别设备。别名由后端保存。

## DNS 上游管理

### 上游组与协议

| 上游组 | 说明 |
|---|---|
| 国内 `domestic` | 国内解析组 |
| 国外 `foreign` | 海外解析组，可配置 SOCKS5 |
| 国外 ECS `foreign_ecs` | 支持 ECS 子网设置，可配置 SOCKS5 |
| 代理 `proxy` | 代理解析组 |

上游编辑器支持 **UDP、TCP、TLS（DoT）、HTTPS（DoH）**。可设置名称、服务器地址、可选拨号地址和查询超时；可用字段随上游组变化。

ECS 字段适用于国外 ECS 组，支持 IPv4 / IPv6；界面提示的默认前缀分别为 `/24` 与 `/56`。

### 管理与健康统计

- 新增、编辑、启用 / 停用、删除上游节点；启用节点排列在停用节点之前。
- 按解析组查看请求份额、平均响应、请求数、并发采纳率、错误数与成功率。
- 有错误的节点可点击错误数量查看错误详情。

“采纳数”用于观察并发查询中某节点响应被选用的情况，不等同于请求总数。

## 规则管理

### 本地名单

| 名单 | 用途 |
|---|---|
| 白名单 / 黑名单 / 灰名单 | 维护对应的放行、拦截与分流名单 |
| 强制 RealIP | 管理强制返回真实 IP 的域名 |
| DDNS 域名 | 维护 DDNS 相关域名名单 |
| PCDN 域名、IPv4 / IPv6 规则 | 维护 PCDN 相关域名与规则 |
| 客户端 IP / 直连 IP | 管理客户端与直连 IP 列表 |
| 重定向 | 维护后端支持的重定向规则 |

编辑器一行一条，点击「保存」提交；「下载列表」导出当前编辑器内容。具体规则语法与匹配行为以 FJG4O 后端为准。

切换名单时会保留未保存草稿，并显示是否存在未保存修改。草稿属于当前浏览器会话，只有保存成功的内容才写入后端。读取失败时禁止保存，避免用空内容覆盖已有规则。

### AdGuard 广告拦截

- 添加、编辑、启停与删除广告规则订阅。
- 单独更新或更新全部，设置自动更新与更新间隔（小时）。
- 查看规则数、上次更新时间及下载失败信息。
- 订阅下载后按 TXT 保存并保留 AdGuard 语法；启用的来源合并为 `rules/compiled/adguard.txt`。

规则订阅维护与「系统管理」中的广告屏蔽开关分别控制规则来源和运行时启用状态。

### 在线分流与 SRS

支持五类来源：**国内规则、国外规则、GeoIP CN、Geosite CN、Geosite 非 CN**。

后端按内容识别来源格式，并转换为 SRS；界面可展示以下识别结果：

| 来源格式 | 界面显示 |
|---|---|
| SRS | `SRS` |
| DAT | `DAT → SRS` |
| Clash YAML | `YAML → SRS` |
| sing-box JSON | `JSON → SRS` |
| TXT、Surge、dnsmasq、hosts、Quantumult X | `TXT → SRS` |

具体来源能否识别由后端决定。多数据集 DAT 在更新时需要选择数据集。

每个订阅可设置启停、自动更新与更新间隔，并支持单条 / 批量更新。来源缓存位于 `rules/online/规则组/`；同组来源合并去重后生成 `rules/compiled/规则组.srs`，供运行时加载。

规则更新请求最多等待 5 分钟，批量更新期间显示“更新中…”并禁止重复提交。等待超时或连接中断时显示“结果待确认”：服务器可能仍在下载、转换规则，请稍后刷新查看更新时间；只有收到明确的失败结果才计为失败。

## 系统管理

### 多级缓存

展示全部缓存、国内缓存、国外缓存、国外 ECS 缓存的请求数、条目数、命中率和过期命中比例。

点击「查看」打开缓存内容；支持单个缓存池清空与全部清空，清空前显示确认提示。

### 功能开关

| 开关 | 页面说明 |
|---|---|
| 请求屏蔽 | 对无解析结果的请求进行屏蔽 |
| 类型屏蔽 | 屏蔽 SOA、PTR、HTTPS 等请求类型 |
| 广告屏蔽 | 启用 AdGuard 规则拦截 |
| IPv6 屏蔽 | 屏蔽 AAAA 请求类型 |
| 核心缓存 | 启用最终结果缓存 |
| 过期缓存 | 允许国内与国外缓存的过期响应 |
| 指定 Client FakeIP | 对指定客户端使用对应的 FakeIP 分流策略 |
| 指定 Client RealIP | 对指定客户端使用对应的 RealIP 分流策略 |

两种指定客户端策略在 UI 中互斥启用；具体解析行为以服务端配置和对应名单为准。

### 自动分流数据与 Requery

- 查看自动分流列表条目数，保存或清空自动分流数据。
- 手动触发分流缓存刷新、查看任务状态、请求取消正在运行的任务。
- 配置定时任务：是否启用、执行间隔（分钟）、域名刷新天数和首次执行时间。
- 页面提供服务重启入口，执行前显示确认提示。

## 外观与交互

### 玻璃材质与字体

- 深色 / 浅色玻璃主题，Logo 随主题切换。
- 五组预设光影：深空暖金、极光深海、暗夜翡翠、日落琥珀、纯净暗黑。
- 独立调整玻璃模糊度、面板遮盖度（越低越透明）与背景暗化。
- Noto Serif SC 宋体风格标题、Instrument Serif 衬线数字；字体随项目本地提供。
- 顶部导航随滚动收拢为圆角浮动栏；解析路径粒子动画可开关。

### 字体选择

打开「外观 → 品牌与字体」，分别调整标题字体、指标数字与界面文字。默认保留 Noto Serif SC 标题和 Instrument Serif 数字。

字体选择即时生效，网页修改先保存为当前浏览器的本机预览。支持 TTF / OTF / WOFF / WOFF2；通过「导出共享配置」和服务器 `configure-ui.py` 导入后，其他设备刷新即可读取字体文件和用途。已有本机覆盖可点击「跟随服务器」。域名、IP 与日志继续使用等宽字体。项目默认字体来自本地 WOFF2，无需在线字体服务。详见 [静态共享配置](SHARED_UI.md)。

侧栏的状态标题与地址分别居中。鼠标点击使用柔白细边，键盘操作保留单层清晰焦点提示，深浅主题自动适配。

### 壁纸怎么保存

打开「外观 → 流光毛玻璃 → 壁纸」设置当前背景。羊皮纸皮肤不显示壁纸及其设置。

| 操作 | 保存方式 |
|---|---|
| 选择本地图片 | 选择后自动保存并应用；等待「已保存到当前浏览器」 |
| 输入在线图片 URL | 点击「应用」或按 Enter；验证图片后保存 |
| 点击「恢复默认」 | 清除当前自定义背景选择，保存默认背景 |
| 切换预设光影 | 保存所选预设 |

每次选择替换当前壁纸，不再提供图库、重命名和批量保存。旧版图库当前使用的壁纸会继续显示。较大的本地图片使用 IndexedDB 保存；写入失败会提示错误并保留原壁纸。

壁纸、主题和玻璃参数保存在**当前浏览器、当前站点地址**，不会跨设备同步。更换浏览器或改变访问地址 / 端口会使用另一份站点存储，清除站点数据会清除已保存壁纸。

### 导航、键盘与手机

- 顶部搜索可搜索域名、客户端或跳转页面，按 Enter 执行。
- 抽屉、对话框与主要交互支持键盘操作；界面响应系统的减少动态效果偏好。
- 手机提供底部导航、记录卡片与名单类别选择器，适配较窄屏幕。

## 常见问题

**为什么趋势图暂时为空？**

当前浏览器会话至少需要三次有效采样。先保持页面打开并等待自动刷新，也可以使用顶部刷新按钮；趋势不读取服务器的长期历史数据。

**为什么换电脑后看不到自己的壁纸？**

壁纸仅保存在当前浏览器、当前站点地址，不会跨设备同步。更换浏览器或访问地址会使用另一份站点存储。

**手机能修改配置吗？**

可以使用同一 Web 控制台的手机布局。规则、上游和系统操作仍需要后端与对应插件可用。

**下载完整包还是 UI 升级包？**

新安装选择完整包；已有 LocalDNS 服务时选择 UI 升级包。平台、安装命令、校验与回退步骤见 [安装说明](../INSTALL.md)。
