# FJGLI 管理操作复核

日期：2026-10-22。目标：FJGLI / UI 2026.10.22.3。

## 发现与修复

真实 FJGLI 保存并更新五类分流订阅后，返回的来源可能没有 `detected_format`、`rule_count` 或 `last_updated`，成功更新以 `changed` 布尔值确认。此前保存流程强制要求格式元数据，因此出现“配置已保存，但来源尚未识别”的误报。

现保留旧核心完整元数据校验及待选择数据集的错误路径，并接受来源有效、`changed` 为布尔值的成功更新。不从 URL 后缀推断格式，不将缺失数量显示成 0。广告编辑及启停统一剔除只读 `last_error`、`line_report`，不再描述旧版编译文件路径；本次未复现行报告导致 HTTP 400。

浏览器复核发现：直接进入 DNS 页面时，静态初始核心标签仍为 FJGIR，只有进入概览才会读取状态并刷新。现初始标签与 FJGLI 发行元数据一致，构建完整性验证增加对应校验。

## 测试入口与边界

`tools/verify_backend_contracts.cjs` 仅允许上述隔离监听地址及专用测试目录。`tools/backend_contract_fixture.py` 提供本地订阅内容并监管测试核心；启动前强制校验监听地址、已关闭的自动更新及计划。准备副本时按上述要求修改其配置，切勿指向生产安装目录。

本机构建客户端：

```sh
node tools/verify_backend_contracts.cjs --base=http://127.0.0.1:19099 --fixture=http://127.0.0.1:19096 --output=/absolute/test-output --build-only
```

将生成的 `audit-backend-client.cjs` 与测试脚本复制到运行隔离核心的 Linux 主机，以 `--client=/absolute/audit-backend-client.cjs` 执行相同命令并去掉 `--build-only`。报告写入 `--output`。Node 仅供隔离验收使用，生产运行不依赖 Node。

上述检查覆盖当前设备的常用管理操作；ARM64、其他发行版、全部第三方规则格式、外部订阅服务器和长时间调度未逐一实机测试。网络可达性与界面兼容性分别核对，原用户上游不因本次检查被改写。私有配置、备份与实机截图不进入公共仓库。
