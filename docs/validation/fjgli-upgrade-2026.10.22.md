# FJGLI 完整迁移验收

日期：2026-10-22。目标版本：FJGLI / UI 2026.10.22.1。

## 实机迁移

- Alpine Linux 3.23.3、x86-64、OpenRC；旧核心 FJGIR，选择已确认 CPU 支持的 amd64-v3。
- 先在安装目录外归档整个旧安装和服务文件，下载到本机并核对 SHA-256。上游和手工规则强制备份，原有客户端别名与自定义订阅一并保留。
- 首次切换检查发现备份后国内上游被修改，工具在停服前拒绝切换。重新备份并下载最新设置后完成更新，说明变更保护实际生效。
- 全新运行目录整体替换 `/opt/localdns`，旧目录保留在同级回退目录；兼容库、共享名称、Logo、字体、站点配置和 UI 更新服务配置均保留。
- 成功启动 FJGLI，TCP/UDP DNS 均返回有效应答；核对 4 个上游组、4 个别名、11 类手工名单、订阅数量与名称、功能开关和 150 MB 内存预算。
- 新内核从保留的在线来源重新构建 5 个分流编译文件；新装模板同样重新编译公开来源，国内域名规则超过 11 万条。
- 日志容量保留 100000，目录保留 `logs`；每周刷新计划及下次执行时间正常读取。旧运行缓存、历史学习状态与旧查询记录没有整目录回填。
- 原代理进程的 PID 和启动标识、防火墙实际规则均与切换前一致；UI 更新服务恢复运行。

## 界面和接口

- 旧 `/plugins/`、`/api/v1/audit/` 和 `/api/v2/audit/` 示例接口在 FJGLI 返回 404，新 API 可正常读取。
- 在隔离实例验证别名、手工名单、开关和分流订阅保存；验证新日志状态、容量、目录、统计、分页及刷新计划返回字段。
- 浏览器实机读取概览、查询日志、审计控制、名单工作台、在线分流和系统管理，显示 FJGLI 与新版 UI；原品牌、别名及订阅正常显示。
- 对旧操作接口集中适配，写入失败不重复提交；客户端策略串行保存，关闭相反旧开关不会清除刚选中的新版策略。
- 按组更新只更新对应组的启用来源，不重复触发全局更新；网络超时仍作为结果待确认反馈。
