# FJGIR 与自定义查询日志目录验收

日期：2026-10-21。先实机验证 FJGIR / UI 2026.10.21.2-local，再以相同功能代码整理为正式发行版 2026.10.21.2。

## 变更

- 在「查询日志 → 审计控制」增加日志存储位置，支持 Linux 相对路径和绝对路径。
- 复用核心的 GET / POST `/api/v1/audit/settings`，显示实际路径、内存和磁盘占用及条目数。
- 目录切换前提示当前查询记录会清空；保存失败保留草稿；重复提交在保存期间被阻止。
- 不支持该接口的旧核心明确显示兼容性提示；网络、权限或返回格式错误显示读取失败并允许重试。
- 审计控制移入 logs 模块，继续提供原有容量、开关及清空操作。

## 备份与配置保留

升级前完整目录、config、rules/manual、ui/custom 和 ui/config.js 已归档，下载至本机并核对 SHA-256。切换前另外停服归档 config、rules、generated 和 cache；旧内核与旧 UI 保留在服务器工作目录。

服务器回退材料与本机私有归档单独保存，不随 Git 或发行包分发。

保持原始配置文件及自定义规则的校验值，核对上游 API 内容等价；代理核心及配置服务进程未重启，防火墙规则未变化。原 `memory_limit_mb: 150` 由 FJGIR 兼容读取为 150 MB DNS 缓存，无需改写配置。日志目录沿用 `logs`，实际为 `/opt/localdns/logs`；容量仍为 100,000 条。

## 隔离运行结果

- 使用原配置副本，在回环管理端口 19099、DNS 端口 2053 验证；隔离实例的订阅自动更新与定时任务禁用。
- UDP/TCP DNS 查询、查询日志、统计、排行、上游、手动规则、订阅和 Requery 接口通过。
- 自定义绝对目录保存成功并写入 config/settings/audit.json；2,200 次查询触发 `query-000001.log.gz`，证实磁盘写入。
- 不可写目录返回 HTTP 400，原目录及查询记录保留。
- 切换目录后当前查询记录变为 0，原压缩文件留在旧目录，不自动迁移。
- 重启后目录设置保留，当前查询记录清空；写入压缩日志后重启也验证了这一行为。
- 隔离测试期间生产进程、原配置和自定义规则未发生变化。

## 上线与前端验收

- 新核心及界面切换后 UDP/TCP DNS、管理 API、配置和规则核对通过；服务就绪时间约 0.54 秒（包含停服、状态归档及启动）。
- 首次切换因防火墙快照包含时间戳和流量计数触发自动回退；确认原配置及 DNS 恢复后，改为比较实际规则、链和策略，重新切换成功。
- `npm run --prefix frontend check`：类型检查、102 项测试、ESLint 与构建完整性校验通过。
- Impeccable 对新增审计界面及日志 CSS 的机械检查无发现。
- 浏览器验证浅色桌面及深色 390 × 844 手机视图；手机弹窗无横向溢出，目录错误提示、草稿保留和目录未变更反馈正常。
- 最终版本元数据与内核标签已核对。默认路径保持不变，用户可在界面保存 VM 上的其他可写目录。
